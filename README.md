# asl-spec

> Agent Specification Language (ASL) — Formal Syntax & Runtime Grammar

`asl-spec` defines the formal grammar, AST specification, and execution semantics of the Agent Specification Language (ASL).

## Specification Overview

- **Formal Grammar**: EBNF definitions for agent state transitions and tool interactions.
- **AST Schema**: JSON/Protocol Buffer schemas for agentic protocol representation.
- **Verification Axioms**: Deductive proof rules for agent behavioral guarantees.

## Ecosystem Integration

Provides the standardized interchange format for agentic workflow definitions and BFT ledger logs.
